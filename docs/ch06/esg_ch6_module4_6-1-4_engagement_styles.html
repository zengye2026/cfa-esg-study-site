Engagement Styles in Practice

本页覆盖第 6 章 6.1.4：投资者如何在实践中实现 engagement，包括由谁来做、借助哪些服务商、不同团队传统带来的目标、风格和语气差异。

总逻辑等式：Engagement style == 执行主体 + 服务支持 + 团队传统 + 投资组合结构；Governance heritage == board first / top-down；E&S heritage == issue or sector first / often bottom-up escalation。

执行线

参与可自做，也可委托

资产所有者、基金经理、组合经理、stewardship specialists 和外部服务商都可能参与，关键看谁有资源、规模和责任。

风格线

治理和 E/S 的起手式不同

治理问题常从董事会和主席切入；环境社会问题常从具体议题、行业和可持续发展团队切入。

组合线

投资方式影响参与方式

集中主动组合更适合公司定制式参与；广泛分散或被动组合更自然采用议题式、行业式参与。

Who Engages 谁来执行 engagement

✓
有些 asset owners 会通过内部团队直接与公司 engagement，作为投资组合的 steward。
✓
有些 asset owners 期望外部 fund managers 交付 stewardship 工作。
✓
Fund managers 内部可以由 portfolio managers 负责 stewardship，也可以由 stewardship specialists 负责，或二者结合。
✓
Engagement activities 也可以完全外包给 specialist stewardship service providers。
✓
几乎所有机构投资者至少部分依赖 proxy voting advisory firms。
✓
Proxy advisers 提供上市公司分析和投票建议，并帮助机构建立投票决策框架。
✓
其他 stewardship service providers 会代表投资者进行不同程度的 engagement，相当于 stepping into the shoes of the investor。
✓
服务商通过聚合客户利益形成规模，使公司管理层和董事会更重视对话。

Governance vs E&S Heritage 团队传统影响风格

✓
Engagement styles 与 stewardship teams 的历史背景有关。
✓
有 governance-led engagement 历史的团队，思维和方法与长期做 environmental and social issues 的团队不同。
✓
E 和 S 的重大议题来自公司业务活动性质，因此相关团队往往按 sector 组织。
✓
G 更多由国家法律和代码决定，因此治理团队通常按 geography 划分。
✓
E/S heritage 团队倾向于关注单个环境或社会议题，并在行业或市场范围内大力推进。
✓
E/S 风格对话通常从 investor relations 或 sustainability teams 开始，再向 senior management 和 board 升级。
✓
Governance heritage 团队往往先关注单个公司，从 chair 开始，常借助 company secretary，再通过 board 向 management 延伸。

Top-Down / Bottom-Up 自上而下与自下而上

✓
PDF 用 top-down 和 bottom-up 描述这些不同路径，但提醒这只是一般化概括。
✓
多数 investment houses 会混合使用两种方式。
✓
Company-focused、bottom-up engagement 更自然适合 active investment approaches，尤其是 concentrated portfolios。
✓
Issue-based、top-down engagement 更适合 passive 或 broadly diversified portfolios。
✓
Active investors 通常从具体公司及其业务问题出发，形成跨多个议题的定制参与方案。
✓
Passive investors 或广泛分散投资者通常先识别一个议题，再与受该议题影响的一组公司参与。

Issue-Based / Company-Focused 议题式与公司式

✓
Issue-based engagement 通常从新闻、宏观分析、筛查或研究服务商识别出的议题开始。
✓
Issue-based engagement 可能覆盖整个行业或更广泛市场，通常先向所有相关公司发信，再跟进对话。
✓
Larry Fink 给 CEO 的年度信是 BlackRock 作为被动投资者采取 issue-based approach 的例子。
✓
2019 年 BlackRock engagement priorities 包括治理、董事会多样性、战略和资本配置、长期薪酬、环境风险机会、人力资本管理。
✓
Issue-based approach 常伴随 best practice examples，可通过推动同行采用最佳实践来推动行业进步。
✓
Company-focused engagement 旨在改善单个公司多个相关 ESG 议题的实践，同时提升 ESG 和投资表现。
✓
Company-focused 对象常来自投资表现不佳公司，或触发特定财务/ESG 指标的公司。
✓
Company-focused 起点通常是直接与 senior management 对话，然后到 board。
Logic Equations

逻辑等式卡片：从主体到风格

每张卡都按“原文要点、中文解释、逻辑等式、投资影响/考点提醒”整理。
1. 执行主体
Who

原文要点：Asset owners 可直接参与，也可要求外部 fund managers 做；fund managers 内部可由 portfolio managers、stewardship specialists 或两者结合完成。

中文解释：参与不是只有一种组织方式。谁最有规模、资源和接近公司的渠道，谁更可能承担实际对话工作。
执行主体
==
asset owner 直接做 + fund manager 做 + specialist provider 外包做
基金经理内部
==
portfolio manager + stewardship specialist + 两者协作
投资影响/考点：看到“who delivers engagement”时，不要只选 asset owner；很多情况下外部 fund manager 或服务商才是执行方。
2. Proxy advisers vs Overlay providers
Service

原文要点：Proxy advisers 主要提供投票分析和建议；overlay service providers 可代表客户进行投票建议和直接 engagement，客户不一定把资金交给其管理。

中文解释：proxy adviser 更像“投票顾问和处理工具”；overlay provider 更像“替客户穿上投资者外衣去做 stewardship”。
Proxy adviser
==
投票分析 + 投票建议 + vote processing support
Overlay provider
==
投票建议 + 直接参与 + 聚合客户影响力
投资影响/考点：题干若说“advances clients' engagement activities even if not investing clients' funds”，对应 overlay service provider。
3. Governance-led 风格
G

原文要点：Governance heritage 团队通常先关注单个公司，从 chair 开始，常通过 company secretary 协助，再通过 board 向 management 延伸。

中文解释：治理问题常由董事会结构、审计、薪酬、法律和治理代码驱动，所以进入点往往是董事会层面。
Governance-led
==
company first + chair / board first + geography split
路径
==
chair → board → senior management → investor relations
投资影响/考点：Practice Problems 会考：有 governance-led history 的投资者最可能先与 board of directors / chair 对话。
4. E&S-led 风格
E/S

原文要点：Environmental and social teams 往往按 sector 组织，围绕具体 E/S 议题在行业或市场范围内推进。

中文解释：E/S 风险来自公司业务活动性质，例如气候、水、供应链、人权，因此常按行业找共性问题，再推动一组公司改善。
E&S-led
==
issue first + sector organization + IR / sustainability start
路径
==
investor relations / sustainability → senior management → board
投资影响/考点：看到 climate、water、human capital 这类横跨行业议题，常对应 issue-based / top-down 风格。
5. 投资组合决定参与方式
Portfolio

原文要点：Company-focused bottom-up engagement 更适合 active、concentrated portfolios；issue-based top-down engagement 更适合 passive 或 broadly diversified portfolios。

中文解释：持仓越集中，越有动力深入某家公司；持仓越分散，越适合找一个重大议题，对一批公司一起推动。
Active / concentrated
==
company-focused + bottom-up + tailored engagement
Passive / diversified
==
issue-based + top-down + sector or market-wide engagement
投资影响/考点：看到 passive investor、broad portfolio、annual CEO letter，优先想 issue-based approach。
Style Comparison

风格对比：看到题眼就能归类

这页专门训练“看到题干描述 → 反推出风格”。
Governance-led vs E&S-led
Governance
由国家法律和治理代码影响更大，团队常按 geography 划分。
起点
通常从 chair、board、company secretary 开始。
E&S
重大议题来自业务活动性质，团队常按 sector 划分。
起点
通常从 investor relations 或 sustainability teams 开始，再向 senior management 和 board 升级。
Top-down vs Bottom-up
Top-down
从某个议题、行业或市场视角出发，推动一组公司改变。
适合
Passive 或 broadly diversified portfolios。
Bottom-up
从单个公司业务和投资问题出发，定制参与目标。
适合
Active investment approaches，尤其是 concentrated portfolios。
Issue-based vs Company-focused
Issue
先由新闻、宏观分析、筛查或研究服务商识别议题，再对相关公司发信和跟进。
例子
BlackRock CEO annual letter：董事会多样性、长期薪酬、环境风险、人力资本等年度重点。
Company
先选某家公司，围绕多个相关 ESG 和业务问题制定参与方案。
对象
常是投资表现不佳或触发财务/ESG 指标的公司。
Proxy adviser vs Overlay provider
Proxy
提供投票分析、投票建议和投票处理支持，核心在 proxy voting。
Overlay
代表客户进行 stewardship overlay，可能包括投票建议和直接 engagement。
关键差别
Overlay provider 可以推进客户 engagement，即使它没有替客户管理投资资金。
考点
看到 ISS、Glass Lewis 多想 proxy adviser；看到 Columbia Threadneedle REO、Hermes EOS、Robeco、Sustainalytics 多想 overlay 或 engagement service。
反推训练：题干说 “history of governance-led engagement” → board/chair；题干说 “passive investor broad holdings” → issue-based/top-down；题干说 “clients' engagement even not investing funds” → overlay provider。
Common Mistakes

易错点：服务商、风格、组合别混

这一节考试常用“谁做、从哪里开始、哪类组合适合”来设置干扰项。

逻辑等式总表

Who engages == asset owner direct + fund manager + portfolio manager + specialist team + external provider。
Proxy adviser == analysis + voting recommendations + processing support。
Overlay provider == stewardship service + voting advice + direct engagement on behalf of clients。
Governance-led == geography split + chair / board first。
E&S-led == sector split + issue first + IR / sustainability first。
Portfolio fit == active concentrated → company-focused；passive diversified → issue-based。

最容易混的 6 组

Proxy adviser vs Overlay providerProxy adviser 不直接代表客户推动 engagement；overlay provider 可以。
Governance vs E/SGovernance 从董事会/主席切入；E/S 多从 IR 或 sustainability 团队切入。
Sector vs GeographyE/S 团队常按 sector；G 团队常按 geography。
Active vs PassiveActive 集中组合更适合公司式、定制式参与；passive 分散组合更适合议题式、批量式参与。
Issue-based vs Company-focusedIssue-based 先找议题再找公司；company-focused 先找公司再展开多个议题。
一般规律 vs 绝对规则PDF 明确说这些是 generalizations，多数机构会混合使用。
记忆线：主体看“谁做”；服务商看“投票建议还是直接参与”；风格看“从董事会还是议题开始”；组合看“集中主动还是广泛被动”。
Self Test

小测区：只覆盖模块 4

点击“看答案”自测。正式 Practice Problems 会放到最后的三轮练习系统。
01
Engagement 在实践中可以由哪些主体完成？
可以由 asset owners 直接完成，也可以由 external fund managers、portfolio managers、stewardship specialists 或 specialist stewardship service providers 完成。
02
Proxy advisers 的主要作用是什么？
提供上市公司分析和投票建议，并帮助机构投资者处理和执行投票决策。核心是 proxy voting support，不是直接代表客户推动 engagement。
03
Overlay service provider 与 proxy adviser 的关键差别是什么？
Overlay service provider 可代表客户提供 stewardship overlay，包括投票建议和直接 engagement，即使它不替客户投资资金；proxy adviser 主要提供投票分析和建议。
04
有 governance-led engagement 历史的投资者最可能先找谁对话？
通常先找 chair / board of directors，并可能借助 company secretary，再向 senior management 和 investor relations 延伸。
05
Environmental and social heritage 的团队通常如何组织、从哪里开始对话？
通常按 sector 组织，围绕具体环境或社会议题推进；对话常从 investor relations 或 sustainability teams 开始，再向 senior management 和 board 升级。
06
Company-focused bottom-up engagement 更适合哪类投资方式？
更适合 active investment approaches，尤其是 concentrated portfolios，因为投资者更有动力深入某家公司并做定制参与。
07
Issue-based top-down engagement 更适合哪类组合？
更适合 passive 或 broadly diversified portfolios，因为这些投资者持有公司多，通常先识别一个重大议题，再对相关行业或市场中的公司批量参与。
08
BlackRock CEO annual letter 是哪类 engagement approach 的例子？
是 passive investors 采取 issue-based approach 的例子。它从年度重点议题出发，如治理、董事会多样性、战略和资本配置、长期薪酬、环境风险和人力资本管理。

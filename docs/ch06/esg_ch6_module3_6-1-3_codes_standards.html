Stewardship Codes and Standards

本页覆盖第 6 章 6.1.3：stewardship codes 的原则和要求，以及这些要求如何适用于资产所有者、资产管理人和服务提供商。

总逻辑等式：Stewardship codes == 受托责任制度化 + 公开政策 + 监督和参与 + 投票 + 利益冲突管理 + 结果披露；UK 2020 == 从“说打算做什么”升级为“证明做出了什么结果”。

监管支持

结果导向

2020 版强调 outcomes 和 practical effects。

全球应用

原则推广到多市场和多资产类别。

起因

监管相信参与有市场价值

准则不是凭空出现，而是金融危机后对机构投资者消极监督的反思。

变化

2020 版强调结果

以前偏 policy statements，现在要求证明治理、ESG 整合、参与和投票怎样实际服务客户和受益人。

陷阱

利益冲突和集体行动最容易混

基金管理行业起草的准则更可能淡化 conflicts；集体参与要小心 acting in concert / concert party 风险。

Origins 准则起点和监管逻辑

✓
监管者相信 engagement 不仅给投资组合增加价值，也能给市场整体增加价值。
✓
Global Financial Crisis 后，监管对 stewardship 的兴趣来自对机构投资者未能约束银行风险的失望。
✓
Walker Report 要求 FRC 发布 stewardship code，为股东参与提供框架。
✓
2010 年 FRC 发布 UK Stewardship Code，接受较快，尤其在 fund managers 中。
✓
UK Stewardship Code 2010 有 7 项原则，建立在更早的机构股东责任原则基础上。

UK Stewardship Code 2020 原则和最大变化

✓
UK Stewardship Code 2020 包含 12 项适用于 asset owners and managers 的原则。
✓
2020 版还新增 6 项适用于 service providers 的原则。
✓
2020 版最大变化是提高 practical delivery 要求，要求每年报告 activity 和最重要的 outcomes。
✓
仅报告活动不够，每项原则相关 outcomes 都要报告，并提供实际服务客户和受益人的具体例子。
✓
投资者不能再用充满雄心表述的 policy statements 满足准则要求，而要展示实际效果。
✓
原则 1-8 是 stewardship 的基础，原则 9-12 关注 engagement responsibilities 的实际履行。
✓
原则 7 和 8 要求 ESG factors 整合进投资流程，并有效监督 service providers。
✓
原则 9-12 涉及 engagement 和 voting，要展示因为参与活动导致公司或其他被投资产发生实质改变。

Principle 4 and Global Codes 系统性风险和全球扩散

✓
UK 2020 最有挑战性的原则之一是 Principle 4，要求识别并回应 market-wide and systemic risks。
✓
该原则要求签署方披露其识别和回应系统性风险的有效性评估。
✓
Australian Asset Owner Stewardship Code 有类似期望：鼓励金融系统和监管政策与长期投资者利益对齐。
✓
ICGN 2020 也讨论投资者就系统性风险与公共政策制定者沟通的需要。
✓
日本 2020 stewardship guidance 小幅借鉴英国，包括报告 engagement outcomes，但重要性没有 UK 2020 那么突出。
✓
全球各地已有类似准则，包括 ICGN、EFAMA、ACSI、AMEC、香港、印度、日本、马来西亚、新加坡、南非、韩国、瑞士、美国等。

Shared Principles and Conflicts 共同原则、利益冲突和集体参与

✓
除 UK 2020 外，各国 stewardship codes 的原则通常很相似，多沿袭英国 2012 版的七项原则。
✓
常见原则包括公开 stewardship policy、定期 monitoring、必要时 active engagement、thoughtfully intelligent voting、诚实开放报告。
✓
有时出现但不一定都有的原则包括 conflicts of interest 管理，以及愿意与其他机构投资者集体行动。
✓
由 fund management industry 起草的准则更可能淡化 conflicts，由监管支持更强的准则更重视 conflicts。
✓
EFAMA Stewardship Code 与英国 2012 版很像，但不包括 conflicts 原则，几乎回避该问题。
✓
Collective engagement 有争议，因为可能被担心形成 concert parties，即投资者合力控制公司但未发起正式收购。
✓
当前准则通常说适用于所有资产类别，但语言和实践仍显露出最初侧重 public equity。

Law and Regulation SRD II 与 ERISA

✓
EU Shareholder Rights Directive II 于 2019 年 6 月生效，会提高各国本地投资者 stewardship 期望。
✓
SRD II 名称是股东权利，但实质更强调 shareholder responsibilities。
✓
美国 ERISA 要求 advisers 以 beneficiaries 的 fiduciaries 身份行动，fund management firms 在美国制度下被视为 advisers。
✓
ERISA 相关义务包括基金会在被投公司 general meetings 投票并与公司 engagement。
✓
2018 年解释更支持 stewardship：如果投票和代理权使用预期能提升投资经济价值，并考虑成本，则 fiduciaries 可以这样做。
✓
ERISA 语境下，engagement 需要与 beneficiaries 的价值有明确联系，不能只是为了纯社会政策目标。

1. 准则为什么出现
Origins

原文要点：GFC 后监管对机构投资者未能有效约束银行风险感到失望，Walker Report 推动英国发布 stewardship code。

中文解释：准则的本质是把“投资者应该负责任地监督公司”制度化，避免机构投资者只做沉默股东。
准则起点
==
金融危机反思 + 机构投资者参与不足 + 监管推动
准则目的
==
给 shareholder engagement 建立原则框架
投资影响/考点：看到 Walker Report、GFC、FRC，联想到 UK Stewardship Code 的监管起点。
2. UK 2020 最大变化
Outcomes

原文要点：UK Stewardship Code 2020 最大变化是提升 practical delivery，要每年报告 activity 和 outcomes。

中文解释：过去可以说“我们有政策、我们有意愿”。2020 版更像复核底稿：你做了什么、结果是什么、怎么证明对客户和受益人有用。
UK 2020
==
activity 披露 + outcome 披露 + concrete examples
最大变化
==
从 policy statements 转向 practical effects
投资影响/考点：Practice Problems 会直接考：2020 版最重大变化是要求报告 engagement actions 的 practical effects / outcomes。
3. 12 项原则的结构
Structure

原文要点：12 项原则可分为基础性 stewardship 原则和 engagement responsibilities 的实际履行。

中文解释：前半部分看投资机构自己有没有治理、文化、资源、冲突管理、ESG 整合和服务商监督；后半部分看它怎样 engagement、collaboration、escalation 和行使权利。
Principles 1-8
==
机构基础 + ESG 整合 + 服务商监督
Principles 9-12
==
engagement + collaboration + escalation + rights
投资影响/考点：不要只把 code 理解成投票规则，它还覆盖机构治理、资源、激励、冲突、客户需要和服务商监督。
4. 系统性风险原则
Principle 4

原文要点：UK 2020 Principle 4 要求识别和回应 market-wide and systemic risks，是最具挑战性的原则之一。

中文解释：这不只是管单家公司，而是要求投资者关注市场、金融系统、社会和环境系统是否健康运行。
Principle 4
==
识别系统性风险 + 回应系统性风险 + 披露有效性
相似代码
==
Australian Asset Owner Stewardship Code Principle 5
投资影响/考点：题干若问哪项准则含有 market-wide financial system / long-term investors alignment，答案指向 Australian Asset Owner Stewardship Code。
5. 利益冲突和集体参与
Risk

原文要点：不同准则对 conflicts of interest 处理差异大；collective engagement 有 concert party 争议。

中文解释：基金管理人可能与被投公司或客户有商业关系，投票和参与不一定天然独立；多个投资者联合行动也可能被监管担心是在变相控制公司。
Conflicts
==
商业关系 + 客户利益差异 + 个人关系 + 投票/参与偏差风险
Collective risk
==
协作影响力 + acting in concert 担忧 + concert party 风险
投资影响/考点：由 investor groups 或 fund management industry 起草的 code 更可能忽略 conflicts；EFAMA 是典型例子。

Common Mistakes

易错点：准则题先抓关键词

这一节名称多，但考试通常抓几个关键词：outcomes、conflicts、systemic risks、concert parties、value link。

逻辑等式总表

UK Code origin == GFC + Walker Report + FRC + shareholder engagement framework。
UK 2020 biggest change == practical delivery + annual activity and outcome reporting。
Principles 1-8 == stewardship foundation；9-12 == engagement and voting delivery。
Principle 4 == market-wide and systemic risks。
Conflicts risk == more likely downplayed in codes drafted by fund management industry。
Collective engagement controversy == concern over concert parties / acting in concert。

最容易混的 6 组

Policy statements vs Outcomes2020 版重点不是更漂亮的政策，而是活动结果和实际效果。
Activity vs Practical effects只说做了多少参与不够，要说明公司或资产发生了什么实质改变。
Conflicts vs Collaborationconflicts 是利益冲突管理；collaboration 是与其他投资者协作。
Collective engagement vs Concert party集体参与不是为了控制公司，但若投资者协同行动过强，会触发监管担忧。
Shareholder rights vs responsibilitiesSRD II 名称是权利，但实质更强调股东责任。
ESG policy goals vs Economic valueERISA 语境下，参与需要与受益人的经济价值有明确联系。
记忆线：看到 UK 2020 先想 outcome；看到 Australia 先想 market-wide financial system；看到 EFAMA 先想 conflicts 缺失；看到 ERISA 先想 fiduciary duty 和 economic value。
Self Test

小测区：只覆盖模块 3

点击“看答案”自测。正式 Practice Problems 会放到最后的三轮练习系统。
01
UK Stewardship Code 最初为什么受到监管推动？
GFC 后，监管反思机构投资者未能有效约束银行风险。Walker Report 要求 FRC 发布 stewardship code，为 shareholder engagement 提供框架。
02
UK Stewardship Code 2020 最大变化是什么？
要求报告 practical effects / outcomes。也就是说，不只披露活动和意图，还要说明参与行动带来的具体结果。
03
UK 2020 对 asset owners and managers 有多少项原则？对 service providers 有多少项原则？
资产所有者和资产管理人 12 项原则；服务提供商 6 项原则。
04
UK 2020 Principle 4 的核心是什么？
识别并回应 market-wide and systemic risks，并披露识别和回应这些风险的有效性。
05
哪个 stewardship code 与 UK 2020 Principle 4 有类似的市场系统对齐要求？
Australian Asset Owner Stewardship Code。它要求资产所有者鼓励金融系统和监管政策运行与长期投资者利益更好对齐。
06
为什么 conflicts of interest 是 stewardship codes 的重要考点？
因为投资管理人可能与被投公司、母子公司、客户或员工个人关系存在利益冲突，影响投票和参与独立性。投资者团体或基金管理行业起草的准则更可能淡化该问题。
07
Collective engagement 为什么会有争议？
因为它可能被担心形成 concert parties，即一组股东在没有正式收购的情况下合力控制或影响公司，触发 acting in concert 相关监管风险。
08
ERISA 语境下，ESG engagement 为什么不能只是纯社会政策目标？
因为 fiduciaries 需要为 beneficiaries 的利益行动。投票和 proxy use 要有合理预期能提升投资经济价值，并考虑成本；不能只为无价值链接的社会政策目标。

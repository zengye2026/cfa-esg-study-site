公司披露、第三方数据、新闻、访谈、专家。

判断重大性

筛掉噪音，识别与投资相关的风险和机会。

形成 scorecard、因子、权重或模型调整。

进入投资决策

影响选股、资产配置、仓位、估值或排除。

检验局限

看依据是否充分、可比、可审计、可解释。

7.1.1

本节不是二选一

PDF 明确说，定性和定量之间界限模糊，没有一种“最适合所有策略”的方法。考试看到“single best approach”要警惕。

隐藏线

数字也需要判断

QESG 看似客观，但选择什么数据、怎么定重大性、给多少权重、选哪个同业参照，都是判断。

7.1.2

挑战不是反对 ESG

挑战的本质是“如何让 ESG 分析有合理依据”。不能因为数据多就直接用，也不能因为数据不完美就完全不用。

7.1.1 ESG 整合方法

✓
ESG 分析可以是定性，也可以是定量，二者边界模糊，没有适合所有投资策略的唯一最佳方法。
✓
定性分析主要以文字形式形成观察和结论，例如披露质量、承诺可信度、薪酬政策、公司文化、产品和服务影响。
✓
披露质量可看是否使用广泛接受的报告框架，例如 SASB/ISSB；也可看 ESG 报告是否经过审计。
✓
定量 ESG 分析使用数字，但仍涉及判断，包括数据选择、重大性、权重和同业参照。
✓
定量例子包括：碳排放、员工流失率、独立董事比例、董事会和管理层多样性等指标。
✓
ESG 数据可汇总为 ESG 分数，并作为资产配置或证券选择模型中的一个因子。
✓
ESG 分数可用于组合仓位调整，但 ESG 因素与财务表现之间的关系仍可能存在争议。
✓
指数策略可向特定 ESG 因素倾斜，例如 gender-tilted indexes。
✓
主题基金可用重大机会地图或 ESG 数据权重，评估与气候、性别等主题的匹配。
✓
AI 和机器学习可用于线上事件监测、卫星图像解读、Scope 3 数据缺口估计。
✓
大量 ESG 数据本身也是挑战；投资者必须先定义重大性，并在使用前评价数据质量和相关性。
✓
PDF 还提到 regenerative AI 可通过分析海量数据，为复杂问题提供解决方案和洞察，从而改善企业 ESG 表现。
✓
混合方法包括 scorecard，把定性判断转为数字评分；也包括根据 ESG 风险调整收入、利润率、资本开支、折现率和估值倍数。
✓
无论采取哪种方法，分析调整都应有合理依据，优于任意或无支持的调整。

Tools ESG 分析工具

✓
Red flag indicators：高 ESG 风险证券被标记，进一步调查或排除。
✓
Company questionnaires and management interviews：向公司询问缺失的管理信息或重大 ESG 数据。
✓
Checks with outside experts：访谈行业专家、客户、供应商、监管者等外部利益相关方。
✓
Watch lists：对高 ESG 风险或高 ESG 机会的证券持续跟踪，例如碳密集公司与碳税政策变化。
✓
这些工具可以由投资经理内部人员完成，也可从外部分析师、ESG 专家或第三方数据库购买。

7.1.2 ESG 整合挑战与批评

✓
主要挑战包括发行人 ESG 披露、ESG 分析和决策的主观性、投资机构内部文化和偏见。
✓
许多投资者认为公司 ESG 披露不足：缺失、不完整、不可比或未经审计；公司管理层则可能认为披露要求范围过广且多方要求冲突。
✓
投资者和管理层可能对重大性阈值以及应披露内容存在分歧。
✓
目前尚无完整 ESG 披露的统一共识，且很可能随资产类别而变化；不过证券交易所和监管机构要求 ESG 披露的范围正在扩大。
✓
教材提到一项研究识别出 35 个已有 ESG 披露强制要求的国家和地区，包括 Australia、China、South Africa 和 United Kingdom。
✓
ISSB 于 2021 年由 IFRS Foundation 设立，目标是形成全球可比的可持续披露基线。
✓
ISSB 早期标准基于 TCFD、CDSB、SASB、IIRC 等材料；IFRS S1 和 IFRS S2 于 2023 年完成。
✓
可比性困难还来自第三方 ESG 评级低相关、供应商方法差异，以及文化和地区规范差异。
✓
部分投资经理可能因成本或复杂度，不把 ESG 分析整合进投资流程。
✓
ESG 整合常见批评：纳入表现差公司、标准主观、数据质量问题、回报收益证据受质疑。
7.1.1 Approaches

方法卡片：从“怎么看”到“怎么放进投资流程”

每张卡都按“原文要点、中文解释、逻辑等式、投资影响/考点提醒”整理。
1. Qualitative ESG Analysis 定性分析
Words
原文要点
定性 ESG 分析通常以文字形式形成观察和结论，例如看披露质量、承诺可信度、薪酬绑定、公司文化和产品社会影响。
中文解释
定性分析像审计访谈和管理层评价：不是只看数字，而是判断“这家公司说的、做的、治理文化是否可信”。
定性 ESG
==
披露质量 + 承诺可信度 + 薪酬激励 + tone at the top + 产品社会影响
投资影响/考点：看到 credibility、culture、tone at the top、commitment、board-level committee，优先联想到定性分析。
2. Quantitative ESG Analysis 定量分析
Numbers
原文要点
QESG 使用数字，例如碳排放、员工流失率、独立董事比例、董事会和管理层多样性；也可汇总为 ESG 分数并进入模型。大型数据集可能覆盖数千家公司和大量数据点，并通过 API 高效处理。
中文解释
定量不是“完全客观”。选择哪个指标、给多大权重、和谁比较，本身仍是专业判断。
定量 ESG
==
指标数据 → 评分/因子/权重 → 资产配置、选券、仓位或指数倾斜
投资影响/考点：看到 metrics、scores、position sizing、factor model、tilt、peer comparison，优先联想到定量分析。
3. QESG in Systematic Strategies 系统策略中的 QESG
Model
原文要点
QESG 可使用复杂数学模型、数据分析、AI 和算法，常见于系统化投资和指数策略；基本面集中持仓也会混合使用定性和定量，例如 GPIF 和指数提供商曾创建 gender-tilted versions of broad market indexes。
中文解释
系统策略像“批量筛查”：处理大量证券和数据点。基本面策略像“单家公司深挖”：数字和判断都要用。
系统 QESG
==
大数据集 + 因子模型 + API/算法 + 定期权重调整
投资影响/考点：不要把 QESG 误解为只适合单家公司访谈，它更常用于大样本、指数和系统化策略。
4. Artificial Intelligence and Algorithms 人工智能与算法
Efficiency
原文要点
AI 可快速分析线上事件、解读卫星图像、评估碳足迹和自然环境影响，也可帮助估计发行人披露中的 Scope 3 缺口。PDF 还提到 regenerative AI 可通过海量数据分析提供解决方案和洞察。
中文解释
AI 是放大器：它能更快找到线索，但不能代替分析师判断重大性、数据质量和与投资的相关性。
AI/算法
==
海量数据 → 快速识别事件/图像/缺口 → 仍需重大性和质量检验
投资影响/考点：看到 satellite imagery、online incidents、Scope 3 estimates，多半考 AI 在 ESG 数据处理中的作用。
5. Hybrid Approach 混合方法
Bridge
原文要点
投资者常用定性和定量结合。Scorecard 可把定性判断变成数字分数；模型输入也可根据 ESG 风险调整。
中文解释
混合方法是本章最重要的桥：先判断问题，再把判断转成评分、收入假设、利润率、资本开支、折现率或估值倍数。
混合分析
==
文字判断 → 分数/假设 → 估值模型或投资流程
投资影响/考点：看到 scorecard、1 to 5 rating、financial model inputs，就是“定性转定量”。
6. Reasonable Basis 合理依据
Discipline
原文要点
不论采用哪种方法，基于合理依据进行分析调整，优于任意或没有支持的调整。
中文解释
这句话很像审计底稿原则：结论可以有判断，但判断要有证据链，不能拍脑袋。
合理调整
==
重大 ESG 因素 + 可解释证据 + 一致模型处理
投资影响/考点：考试若出现 arbitrary、unsupported adjustment，通常是不好的做法。
Tools and ISSB

工具与披露框架：把 ESG 信息变得可追踪

这一部分最像实务工作：先建工具收集证据，再用披露标准提高一致性和可比性。
Red Flag Indicators 红旗指标
Investigate

原文要点：高 ESG 风险证券会被标记，进一步调查或排除。例如董事会缺乏多数独立性，可直接排除，也可继续看是否有补偿性因素。

红旗
==
异常风险信号 → 进一步调查 / 排除 / 寻找补偿因素
考点提醒：red flag 是“工具”，不是 ESG 因子倾斜本身。
Questionnaires and Interviews 问卷与访谈
Ask

原文要点：当管理信息或重大 ESG 信息不足时，投资者可向公司索取具体数据，也可在公司会议中讨论重大 ESG 问题。

问卷访谈
==
信息不足 → 询问公司 → 补齐重大 ESG 数据和管理解释
实务联想：类似客户访谈和补资料清单，目标是补足判断证据。
Outside Experts 外部专家核查
Corroborate

原文要点：投资者可访谈行业思想领袖、客户、供应商、监管者等利益相关方，并用专家网络、调查或第三方来源补充。

外部核查
==
公司说法 + 专家/客户/供应商/监管者 → 交叉验证
考点提醒：外部专家不是替代公司披露，而是补强和交叉验证。
Watch Lists 观察名单
Monitor

原文要点：高 ESG 风险证券可加入观察名单持续监控；高 ESG 机会证券也可加入名单等待投资时点。例如高碳公司跟踪碳税政策变化。

观察名单
==
已识别风险/机会 → 跟踪事件和价格 → 等待行动点
投资影响：观察名单把 ESG 分析从一次性判断变成持续监控。

ISSB：披露标准为什么重要

定位：ISSB 是 IFRS Foundation 于 2021 年设立的 IASB 姊妹委员会，目标是形成全球可持续披露基线，服务经济和投资决策。
来源：ISSB 标准吸收 TCFD、CDSB、SASB、IIRC 等材料；CDSB、SASB、IIRC 已并入 IFRS Foundation。
IFRS S1：一般要求，聚焦可持续相关风险和机会的重大信息，并强调财务报表与可持续披露之间的一致和连接。
IFRS S2：气候相关披露，涵盖物理风险、转型风险、气候机会、转型计划、气候韧性及 Scope 1、2、3 排放。
ISSB
==
统一披露语言 → 减少标准碎片化 → 提高投资者使用 ESG 信息的可比性

考点提醒：ISSB 有潜力减少 “alphabet soup”。在 ISSB 标准替代 SASB Standards 前，发行人和投资者仍被鼓励继续使用 SASB Standards；要像 IFRS Accounting Standards 一样被广泛采用，还需要各司法辖区的证券监管和法律支持。

7.1.2 Challenges

挑战与批评：不是不用 ESG，而是不能盲用 ESG

这一节最常考“为什么 ESG 整合困难”。用一条线背：披露难、判断难、比较难、落地难、收益证明难。
1. Disclosure Problems 披露问题
Data

原文要点：公司 ESG 披露可能缺失、不完整、不可比或未经审计；投资者和管理层对重大性阈值和应披露内容可能意见不一致。管理层也可能认为 ESG 数据范围太广，且投资者、监管者等多方要求相互冲突。

披露难
==
缺失 + 不完整 + 不可比 + 未审计 + 重大性分歧 + 多方要求冲突
易错提醒：公司没披露某项 ESG 数据，不一定等于风险管理差；但它会提高分析难度。
2. No Full Consensus 尚无完整共识
Framework

原文要点：什么构成完整 ESG 披露尚无统一共识，而且可能因资产类别不同而变化。ESG 报告框架仍比财务报告框架年轻，但强制 ESG 披露要求正在更多市场出现。

标准难
==
披露框架仍在发展 + 资产类别差异 + 监管扩展 + 全球标准化努力
考点提醒：EFRAG 和 ISSB 是区域和全球层面推动披露标准化的重要努力。
3. Comparability and Culture 可比性与文化差异
Context

原文要点：不同报告框架、第三方 ESG 评级低相关、供应商方法差异，以及地区文化规范差异都会影响可比性。

可比性难
==
框架不同 + 评级方法不同 + 文化/地区预期不同
投资影响：同一个治理或劳工问题，放在不同国家可能有不同背景，不能机械套用。
4. Cost and Complexity 成本与复杂度
Process

原文要点：虽然 ESG 整合影响力扩大，但并非所有投资经理都接受；有些机构会因成本或复杂度选择不整合。

落地难
==
数据多 + 流程复杂 + 人员文化偏见 + 成本压力
考点提醒：ESG integration 是投资流程设计问题，不只是买一个数据库。

四类常见批评

Too inclusive：ESG 基金可能仍持有被视为表现差的公司；若目标是排除，应采用排除策略，而不是把 ESG 整合当排除。
Subjective criteria：ESG 因子选择可能主观，甚至反映意识形态或政治观点；资产所有者应选择与自身标准一致的管理人。
Quality of data：数据往往来自公司自身，可能未经审计，验证、比较和标准化有难度；可用多来源交叉验证缓解。
Skepticism of return benefits：有人质疑 ESG 与财务回报证据不充分，原因包括考察期短、行业轮动、拥挤交易和归因困难。
ESG 批评
==
纳入范围争议 + 标准主观 + 数据质量 + 回报归因不确定

Five-Minute Review

考前压缩版：一屏背完整模块

先背公式，再看易错点。公式不是关键词堆砌，而是帮助你反推原文细节。

逻辑等式总表

ESG integration == 把 ESG 风险/机会纳入投资流程，没有单一最佳方法。
Qualitative ESG == 披露质量 + 承诺可信度 + 薪酬绑定 + 公司文化 + 产品社会影响。
Quantitative ESG == 指标/数据 + 重大性 + 权重 + 同业参照 → 模型、仓位、指数或主题。
AI in ESG == 线上事件 + 卫星图像 + 数据缺口估计 → 高效处理，但仍要检验质量。
Hybrid approach == 定性判断 → scorecard/模型假设 → 投资决策。
Tools == 红旗 + 公司问卷访谈 + 外部专家核查 + 观察名单。
ISSB == IFRS Foundation 的可持续披露基线 → S1 一般要求 + S2 气候披露。
Integration challenges == 披露不足 + 主观性 + 文化偏见 + 评级低相关 + 成本复杂。
Criticism == 太包容 + 标准主观 + 数据质量 + 回报证据争议。

最容易混的 6 组

定量不等于无判断QESG 虽然用数字，但数据选择、重大性、权重和同业选择都需要判断。
ESG integration 不等于 exclusionary strategy如果目标是排除“bad actors”，应该用排除策略；ESG 整合可能仍持有这些公司。
Scorecard 是桥，不是原始事实它把定性判断转成数字评分，方便进入模型或比较。
Red flag 不是最终结论红旗可能导致排除，也可能引发进一步调查和补偿因素分析。
ISSB 是披露基线，不是投资评级机构它提供披露标准，帮助投资者获得更一致的信息。
低相关既有坏处也有争论空间评级差异会降低一致信号，但高相关也可能带来群体思维。
建议复习顺序：先背“方法一条线”，再背“挑战一条线”。看到题目里的 words/credibility/culture 就想定性；看到 metrics/scores/tilts/position sizing 就想定量；看到 unsupported/arbitrary 就判为不佳做法。
Quick Check

小测区：只覆盖本模块

这里是 Module 1 的自测题。正式三轮练习系统等整章完成后再统一制作。
01
判断管理层净零承诺是否可信，属于定性还是定量 ESG 分析？
答案：定性分析。题眼是 credibility 和 management commitment，重点是判断承诺、政策和执行是否可信。
02
分析碳排放、员工流失率、独立董事比例，并与同业比较，属于哪类方法？
答案：定量 ESG 分析。这些是可量化指标，可进入评分、因子、权重或组合仓位判断。
03
为什么说 QESG 仍然需要 discretion and judgment？
答案：因为要判断选择哪些数据、哪些因素重大、权重如何设定、同业参照如何选取。
04
把公司治理质量按 1 到 5 分评分，是哪种混合工具？
答案：Scorecard。它把定性判断转成定量分数，便于比较和进入估值或投资流程。
05
一家高碳公司被持续跟踪碳税政策变化，这属于 red flag 还是 watch list？
答案：Watch list。题眼是持续监控政策和事件，等待风险变化或投资时点。
06
ISSB 的 IFRS S1 和 IFRS S2 分别侧重什么？
答案：S1 是可持续相关财务信息的一般披露要求；S2 是气候相关披露，涵盖物理风险、转型风险、气候机会和 Scope 1、2、3 排放等。
07
ESG 整合常见批评中的 “too inclusive” 指什么？
答案：ESG 基金可能仍持有一些被视为 ESG 表现差的公司，因此有人认为它与传统策略差异不够清楚。
08
为什么 ESG 披露问题会影响投资分析？
答案：因为披露可能缺失、不完整、不可比或未经审计，投资者还可能与管理层对重大性和披露范围看法不同。

反推自测

看到 “online incidents, child labor, corruption” 反推什么？
反推 AI/算法在 ESG 中的使用：通过大量线上来源快速识别和量化公司 ESG 事件与风险。
看到 “arbitrary or unsupported adjustments” 反推什么？
反推“合理依据”原则：模型调整应有可解释依据，任意或无支持调整是不佳做法。
看到 “low correlation among ESG ratings” 反推什么？
反推可比性挑战：不同供应商目标和方法不同，ESG 评级不像主要信用评级那样高度一致。

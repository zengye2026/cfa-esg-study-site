Codes

Cadbury 是世界首个正式治理代码。

核心从 accountability 和 alignment 延展。

Comply or explain

遵守原则，或认真解释为什么不遵守。

目的不是机械打勾。

Engagement

投资者与公司主动对话。

让董事会对行动负责，提高决策质量。

Minority rights

防止控制股东抽走利益或稀释持股。

工具包括投票、披露、pre-emption、sunset。

失败暴露

账目失真、舞弊、权力集中、审计失效。

投资者受损

股东、债权人和利益相关方遭受损失。

市场要求改革

监管、交易所、投资者要求提高标准。

治理代码形成

原则、委员会、披露和独立性被明确化。

股东参与加强

对话、投票、代理顾问和 stewardship 发展。

防止控制人利用关联交易、稀释和投票权结构。

Frameworks 治理代码与制度演进

✓
公司失败和丑闻是治理正式化和代码发展的强大驱动力。
✓
英国 1992 年 Cadbury Code 是世界首个正式公司治理代码，源于 Caparo、Polly Peck 等问题。
✓
Cadbury 的核心主题是不应让任何个人拥有不受约束的决策权，因此 chair 和 CEO 不应合并。
✓
Cadbury 建议上市公司设立审计委员会并定期开会，这一做法后来成为全球常见最佳实践。
✓
治理代码由 accountability 和 alignment 两个基本概念发展而来，但会受国家文化、历史和公司法影响。
✓
多数市场使用 comply or explain；荷兰偏 apply or explain；澳大利亚常用 if not, why not。
✓
美国是唯一没有正式公司治理代码的主要市场，主要因公司法由州层面制定。

Scandals 丑闻推动标准升级

✓
Greenbury Report 由英国私有化公用事业高管薪酬争议推动，强调薪酬结构、KPI 和长期释放期透明度。
✓
Enron 和 WorldCom 推动美国 2002 年 Sarbanes-Oxley Act，并创建 PCAOB。
✓
Ahold 和 Parmalat 使欧洲重新审视治理标准、董事会独立性和审计独立性。
✓
2008 年金融危机推动对企业文化、高管薪酬和审计的关注，也推动 stewardship codes。
✓
Dodd-Frank Act 2010 加强银行标准和监管监督。
✓
Olympus 和 Toshiba 推动日本治理标准和 ESG 披露期望快速提升。

Rights 股东参与和少数股东保护

✓
Shareholder engagement 是公司和投资者之间主动对话，投资者表达包括 ESG 在内的关注点。
✓
参与的目的之一是让董事对行动负责，并逐步提升决策质量。
✓
少数股东，尤其机构投资者，关键风险是被控制股东或大股东剥削。
✓
关联交易通常需要更高披露，并可能要求无利益冲突股东批准。
✓
英国上市规则中，超过 5% 的交易触发额外披露；超过 25% 的交易需要股东投票批准。
✓
Pre-emption rights 让现有股东有权按比例认购新股，避免被稀释。
✓
公司 AGM 可能寻求 5% 或 10% 的非优先认购发行授权；香港一般授权可高达 20%，且可能折价。
✓
Dual-class shares 让创始人或特定群体拥有更高投票权，降低其对普通股东的问责。
✓
Sunset clause 要求双重股权在一段时间后合并，CII 主张最多七年后统一。

治理代码：丑闻倒逼出来的制度语言

这里按时间线记，不是为了背年份，而是记住“哪个问题推动哪个制度”。

Cadbury Code

Greenbury Report

Sarbanes-Oxley
Enron、WorldCom 后提高财务报告完整性，并创建 PCAOB。
2003
Ahold & Parmalat
欧洲不能再把治理和审计失败看成美国个别问题。
2008+
Financial crisis
重新关注企业文化、高管薪酬、审计和 stewardship codes。
2011-15

1. 治理代码为什么出现
Cause

原文要点：公司失败和丑闻是治理代码正式化的重要驱动；当公司失败、投资者损失，市场会要求更好的制度。

中文解释：治理制度不是为了漂亮，而是为了防止同类失败反复发生。

Governance codes
==
corporate failure + investor losses + reform pressure
考点提醒：看到 scandal / failure / investors lose money，要反推 governance standards development。
2. Cadbury 的核心
Cadbury

原文要点：Cadbury 认为不应让任何个人拥有不受约束的决策权，并推动审计委员会、chair/CEO 分离等做法。

中文解释：Cadbury 不是单纯讲“多设委员会”，它要解决权力集中和财务监督不足。

Cadbury
==
no unfettered power + audit committee + chair/CEO separation
考点提醒：Cadbury 题眼常见：first formal code、comply or explain、Caparo/Polly Peck、audit committee。
3. Comply or explain
Model

原文要点：大多数市场采用 comply or explain，荷兰 apply or explain，澳大利亚 if not, why not。

中文解释：重点不是机械遵守每条规则，而是如果偏离，就要说明如何仍然满足底层原则。

Code model
==
adhere to standard or explain delivery of principle
易错提醒：Proxy adviser 可能偏严格，但真正的投资者应结合公司情况作独立判断。
4. 美国为什么特殊
USA

原文要点：自日本 2015 年采用治理代码后，美国成为唯一没有正式治理代码的主要市场，因为公司法由州而非联邦制定。

中文解释：美国不是没有治理要求，而是没有一个全国统一的正式治理代码。

USA no code
==
state-level corporate law + no federal corporate governance code
考点提醒：问唯一主要市场，答案是 USA，不是 Japan。
Major Scandals

重大丑闻：从故事记成“失败类型”

每个案例用一条逻辑等式压缩，避免陷入故事细节。
Enron, USA 2001
Off-balance-sheet
问题
利用表外工具和激进会计技术制造盈利假象，审计师 Arthur Andersen 崩解。
失败
董事会监督不足，允许 CFO 参与存在利益冲突的结构，未让外部审计、内审和举报机制有效运行。
教训
提高伦理标准、增强董事会独立性、强化内控和风险框架、限制审计师非审计服务。
式子
Enron == weak oversight + conflicts + aggressive accounting + failed audit environment。
WorldCom, USA 2002
Capitalized expenses
问题
把当期费用资本化，虚增利润和资产，用来掩盖增长下滑。
失败
董事会缺乏对业务和目标实现方式的理解，管理风格专断，内审虽发现问题但监督不够及时。
教训
建立稳健财务控制、适当董事会监督、独立且有伦理的审计师、合规和诚信文化。
式子
WorldCom == simple accounting deceit + autocratic culture + delayed control response。
Ahold, Netherlands 2002-03
Aggressive growth
问题
国际并购扩张，隐藏业绩恶化，涉及合资会计、隐藏成本和供应商返利。
失败
董事会技能和流程没有随业务扩张同步升级，监督国际业务不足；薪酬强调 earnings growth。
教训
监督董事会需独立、有能力、投入足够时间，并能指导战略、财报诚信和高管薪酬。
式子
Ahold == acquisitive growth + weak international oversight + incentive misalignment。
Parmalat, Italy 2003
Fictional cash
问题
通过虚假会计掩盖亏损，最终账上数十亿欧元现金和等价物被发现不存在。
失败
控制股东兼任 chair 和 CEO，财务记录欺诈，举报风险被压制，审计未尽专业谨慎。
教训
委员会结构、独立董事占多数、chair/CEO 分离、独立审计和重新设计内控。
式子
Parmalat == controlling shareholder power + false accounts + audit failure。
Satyam, India 2009
False invoices
问题
创始人承认伪造账目，使用大量虚假发票虚增收入，审计未检查足以揭示问题的银行记录。
失败
董事会监督有限，未清晰区分董事、独立董事和管理层职责，未保护股东重大信息权。
教训
印度强化 accountability、transparency、responsibility、fairness，以及审计师、会计师和独立董事规范。
式子
Satyam == founder fraud + weak board role clarity + audit miss + related-party warning。
Olympus, Japan 2011-12
Hidden losses
问题
长期隐藏亏损，通过高价收购和顾问费安排掩盖财务问题，CEO whistleblower 被免职。
失败
长期任职高管、任人唯亲文化、yes-men 董事会、法定审计人独立性不足。
教训
董事会多元化、问责、透明和包容决策文化，董事理解职责和治理技能。
式子
Olympus == crony culture + hidden losses + weak challenge + whistleblower signal。
Volkswagen, Germany 2015
Emissions
问题
柴油排放测试作弊。表面是环境问题，底层是问责、投票权和监督结构问题。
失败
投票权集中于家族、地方政府和 Qatar；董事会缺少多元意见和专业监督；文化鼓励隐瞒问题。
教训
监督董事会要有相关经验、技能和独立性，并把技术创新人员纳入风险管理。
式子
Volkswagen == concentrated voting power + insular culture + compliance failure。
Wirecard, Germany 2020
Missing assets
问题
长期财务造假和可疑会计，特别审计显示约 19 亿欧元资产缺失。
失败
透明度、问责和监督不足；内控无效；监管和董事会未充分关注媒体调查和红旗。
教训
董事会应建立伦理合规框架和适当委员会；审计师要验证财务报表存在、完整和准确。
式子
Wirecard == fraud allegations ignored + weak controls + auditor/regulator failure。
Shareholder Rights

股东参与和少数股东权利：防止控制人拿走方向盘

这一部分考试常用数字和英文术语设干扰，尤其是 5%、25%、20%、pre-emption 和 sunset clause。
1. Shareholder engagement
Dialogue

原文要点：股东参与是公司与投资者之间主动对话，投资者表达包括 ESG 在内的关注点。

中文解释：它不是简单投反对票，而是通过持续沟通让董事会对行动负责。

Engagement
==
active dialogue + clear concerns + board accountability
投资影响/考点提醒：Engagement 更详细会在第 6 章展开，本章只掌握其服务于 accountability。
2. Minority shareholder protection
Protection

原文要点：少数股东的关键问题是避免被控制股东剥削，保护通常来自公司法、上市规则和治理代码。

中文解释：少数股东怕的不是“没有经营权”，而是控制人用关联交易、稀释、控制投票权把经济利益转走。

Minority rights
==
avoid exploitation by controlling shareholders
考点提醒：Institutional investors 通常属于 minority shareholders。
3. UK class tests
5% / 25%

原文要点：交易影响资产、利润、价值或资本超过 5%，需要额外披露；超过 25%，需要股东投票批准。

中文解释：影响越大，股东越需要信息和投票权，防止公司发生重大变化却不给投资者选择权。

UK class tests
==
5% disclosure + 25% shareholder vote
考点提醒：5% 是披露，25% 是投票，不要倒置。
4. Pre-emption rights
Dilution

原文要点：优先认购权让现有股东有机会认购足够数量的新股，以维持其持股比例。

中文解释：它保护的是“我的股份比例不要被别人绕过我稀释”。大型股权融资常被称为 rights issue。

Pre-emption
==
existing shareholders buy first → avoid dilution
考点提醒：美国并非许多市场那样把 pre-emption 作为公司法基本安排。
5. General mandate in Hong Kong SAR
20%

原文要点：香港一般授权可让董事会发行最高 20% 股本，可能无优先认购且可折价。

中文解释：这对少数股东不友好，因为既可能被稀释，又可能以低价让新投资者进入。

HK mandate
==
up to 20% issue + potential discount + no pre-emption
考点提醒：正式题常直接问 Hong Kong SAR general mandate 的比例，答案是 20%。
6. Dual-class shares and sunset
Votes

原文要点：双重股权通常给创始人或特定群体更多投票权；CII 支持一定早期稳定性，但主张设置 sunset clause。

中文解释：Dual-class 让经济利益和投票权分离，sunset clause 是给这种不平等投票权加“到期日”。

Sunset clause
==
dual-class shares unify after set period
考点提醒：Sunset clause 的作用是降低双重股权长期负面表现风险，不是给少数股东行权证。
Related-party transactions控制人可能把价值从公司转移出去，所以通常需要更高披露和无利益冲突股东批准。
Soft pre-emption即使不是完全法定优先认购，也通常希望大型机构股东能按原比例获得分配。
Dual-class warning投票权集中会降低管理层对普通股东的问责，Volkswagen 是欧洲例子。
Snap exampleSnap 甚至发行无投票权股份，把 dual-class 的治理担忧推得更远。
Audit-style Cases

案例框：用审计复核思路看治理问题

把每个治理问题转成“风险点、证据、影响、程序”，后续做题会更稳。
案例 1：关联交易与少数股东
RPT
风险点
控制股东可能通过关联交易把公司资源转移给自己。
证据
是否有完整披露、定价依据、独立董事意见、无利益冲突股东批准。
影响
少数股东经济利益被稀释或转移，治理折价上升。
式子
RPT risk == controlling shareholder benefit + minority shareholder loss。
案例 2：折价增发和优先认购
Dilution
风险点
董事会绕开现有股东，以折价向新投资者发行大量股份。
证据
授权比例、发行价格、是否给予 pre-emption 或 soft pre-emption、是否有股东批准。
影响
现有股东持股比例和经济价值被稀释。
式子
dilution risk == new shares + no pre-emption + discount。
案例 3：治理丑闻如何倒逼代码
Code
风险点
董事会、审计或文化失灵导致公司失败，投资者遭受重大损失。
证据
是否存在权力集中、非独立董事、内控薄弱、审计失效、激励错配。
影响
市场和监管要求提高治理标准，形成代码、法律或 stewardship 规则。
式子
scandal lesson == specific failure → formal governance response。
Compressed Review

考前压缩：一组式子背完模块 2

这部分之后会进入 Key Facts 汇总和三轮练习的压缩背诵区。

模块 2 主式

Governance codes == scandals + investor losses + reform pressure。
Cadbury == first formal code + comply or explain + audit committee + chair/CEO separation。
SOX 2002 == Enron/WorldCom + financial reporting integrity + PCAOB。
2008 crisis == culture + executive pay + audit + stewardship codes。
Shareholder engagement == active dialogue + ESG concerns + board accountability。
Minority protection == related-party approval + pre-emption + vote on major change + sunset。
UK class tests == 5% disclosure + 25% shareholder vote。
HK general mandate == up to 20% additional shares without consent/pre-emption。

易错点

易错 1：把 Cadbury 和 Enron 混在一起。Cadbury 是英国 1992 年；Enron 是美国 2001 年，推动 SOX。
易错 2：把 comply or explain 理解成必须完全遵守。核心是遵守标准或解释如何实现底层原则。
易错 3：把 pre-emption 当成普通投票权。它保护的是现有股东在新股发行中的不被稀释权。
易错 4：把 5%、25%、20% 混淆。UK 5% 披露、25% 投票；香港一般授权最高 20%。
易错 5：以为 dual-class 永远不可接受。CII 承认早期稳定性，但要求 sunset clause 限制长期负面影响。
模块 2 边界提醒：董事会技能矩阵、DEI、董事独立性、薪酬结构细节会在模块 3 和模块 4 继续展开。
Self Test

自测题：看到题眼，先反推知识点

正式 Practice Problems 会在最后三轮练习系统中完整处理，这里先训练模块 2 的反推能力。
1
世界首个正式公司治理代码是什么？它最常见的遵循模式是什么？
Cadbury Code，英国 1992 年。常见模式是 comply or explain，即遵守建议或解释不遵守如何仍实现底层原则。
2
Enron 和 WorldCom 推动了美国哪项法律？该法律创建了什么机构？
推动 Sarbanes-Oxley Act 2002。该法律创建 PCAOB，作为美国审计标准制定和检查机构。
3
UK class tests 中 5% 和 25% 分别对应什么？
交易影响资产、利润、价值或资本超过 5%，需要额外披露；超过 25%，需要股东投票批准。
4
Pre-emption rights 保护的核心是什么？
保护现有股东维持其持股比例的机会，防止公司发行新股时绕过现有股东造成稀释。
5
Hong Kong SAR general mandate 的题眼数字是多少？为什么对少数股东不友好？
题眼数字是 up to 20%。它可能允许董事会在没有既有股东同意和优先认购的情况下增发，且可能折价，导致少数股东被稀释。
6
Sunset clause 在 dual-class shares 中起什么作用？
Sunset clause 要求不同类别股份在设定期限后统一，消除创始人和普通股东之间投票权差异，降低双重股权长期负面表现风险。
7
为什么 Volkswagen 虽然是排放作弊，也属于治理案例？
因为底层问题包括投票权集中、董事会监督不足、内部控制和公司文化失灵，管理层在封闭且缺少外部挑战的环境中隐瞒问题。

9.1.4 Review
Knowledge Map

第一屏先看一张图：洗绿不是“说错话”，而是证据链断裂

greenwashing 的核心不是绿色词汇本身，而是 claims、data、scope、methodology、actual practice 之间是否一致。考试常考定义、类型、ESA 核心特征和监管/案例。

Greenwashing
可持续表述没有被真实行动、完整范围和可靠证据支撑

1 Claim

公司或产品对 ESG 实践、特征、目标、影响作出表述。

2 Gap

表述与行动、范围、证据、数据或披露不一致。

3 Mislead

消费者、投资者或客户据此形成错误判断。

4 Consequence

信任受损、诉讼、罚款、品牌声誉下降、融资和人才受影响。

5 Response

硬证据、透明数据、生命周期视角、第三方验证、监管处罚。

隐藏逻辑 1：说了什么commitment、product attribute、disclosure、label、advertising。
隐藏逻辑 2：少了什么行动、范围、数据、方法、生命周期、供应链、重要信息。
隐藏逻辑 3：误导谁消费者、投资者、客户、监管者和可持续金融市场。
隐藏逻辑 4：怎么防可验证、可比较、可解释、及时更新、独立验证。
定义题

false statements 是题眼

正式题问 greenwashing，核心是 false statements about ESG practices，用来吸引关注环境友好或可持续实践的客户。

类型题

不是所有洗绿都故意

ESA 特征里明确包括 intentional 和 unintentional，过失或误解监管框架也可能造成 greenwashing。

案例题

看 claim 和 issue 的差距

HSBC、Nestle、Coca-Cola、Walmart、Volkswagen、Danish FSA 等案例都可按“说法 vs 事实/范围/证据”来拆。

定义 Greenwashing 是什么

✓
IOSCO 视角：资产管理人 misrepresent sustainability-related practices 或 investment products 的 sustainability-related features。
✓
范围可轻可重：从发行文件中不当使用可持续术语，到对实体可持续承诺的重大误述。
✓
更一般地，greenwashing 是公司对 ESG practices 作出 false statements，以吸引重视环境友好和可持续实践的客户。
✓
也可能是把金融产品营销成环保，但实际上基本环境标准未满足，从而获得不公平竞争优势。
✓
来源可能是故意欺骗，也可能是绿色雄心没有兑现、知识不足，或不清楚什么才算真实、准确、可识别的绿色资质。

三类 Misrepresentation PDF 明确列举

✓
Commitments without guarantees of action：高层次承诺或净零目标没有后续行动保证。
✓
Product attributes：对产品或生产方法的环境属性作出不实或不完整表述。
✓
Disclosures：披露中隐瞒或误述社会因素及相关重大财务风险，例如安全、坝体、排放等。
✓
正式题问“not an example of greenwashing”时，准确陈述环境收益的 regulatory filing 不是洗绿。

后果 声誉、信任、财务与系统性风险

✓
greenwashing 不只是小声誉问题，而是长期、系统性风险，会削弱公司、品牌和吸引客户、人才、资金、合作伙伴的能力。
✓
营销声明若不完全准确，可能引发 greenwashing litigation，带来时间成本、金钱成本和严重声誉损害。
✓
DWS 案例显示，greenwashing 指控可能带来监管调查、内部控制加强、法律费用和潜在罚款压力。
✓
InfluenceMap 研究被用于说明许多绿色或低碳基金存在夸大或达不到目标的情况，投资者和客户会惩罚误导性声明。

数据反制 为什么只靠标签不够

✓
当标签依赖单一、无法充分测试的元素时，greenwashing 风险上升。
✓
ESG 指标因行业而异，单一指标通常不足以进行有意义公司比较，也不足以全面反映 ESG practices。
✓
研究指出，一些 ESG scoring systems 权重和假设不透明，披露本身可能比真实环境绩效更能预测高分。
✓
ESG ratings and data providers 需要提高 reliability、comparability、interpretability。
✓
反制依靠 traceability、credibility、透明数据、准确计量、可靠方法、硬证据、供应链/第三方服务商纳入验证、第三方认证。
✓
沟通必须 comprehensible and adequate；网站、招股书和所有 sustainability claims 都要更新且适合目的。

直接与间接影响 信任和真实 ESG 投资

✓
最大影响是破坏 consumer trust，并可能损害公众对真实 ESG initiatives and products 的信任。
✓
投资者有权获得真实信息，这有助于维持对金融产品和可持续披露的信心。
✓
真正的 ESG 投资通常表现较好且波动较低，因为公司更有效管理环境、社会和治理风险。
✓
环境风险包括污染监管、水依赖、气候变化导致的业务中断。
✓
社会风险包括罢工、工厂停产、劳工诉讼、不安全或不公平劳动实践带来的负面公众观感。
✓
治理风险包括商业伦理、股东争议、领导层变化、会计不当、税务问题等。
✓
conscious quitting risk：可持续专业人员因雇主价值观不一致而离职。

三个近似概念 Greenhushing / Scopewashing / Competence

✓
Greenhushing：因担心被追责或误解，正在取得进展的企业反而不愿充分披露可持续计划。
✓
Scopewashing：用正面行动掩盖其他负面影响，或只披露部分范围，例如只讲直接排放、不讲能源、运输和材料等间接排放。
✓
Competence greenwashing：董事、高管或员工夸大自身可持续知识、技能和经验。
✓
应对 competence greenwashing：提升全员意识，建立真正 ESG 专家团队，不只看 ESG 自我标签或证书缩写，搭建跨 finance 和 natural science 的多元团队，小机构可与研究机构合作。

Misleading Statements 表述和标签风险

✓
许多 greenwashing 来自 statements and language 的不当选择：宽泛、模糊、暗示可持续但未达到相应程度。
✓
绿色配色、图片和营销手法也可能制造比现实更环保的印象。
✓
European Commission 研究指出大量 environmental claims 模糊、误导、缺乏依据或完全未证实。
✓
绿色标签数量过多、透明度差、验证弱，会削弱消费者信心。
✓
具体细节、计量单位、同类产品比较和 like-for-like comparison，有助于降低误导风险。

ESA 七个核心特征 考试高频

✓
可因 omission 误导，也可因提供 false/deceptive 信息误导。
✓
可发生在 entity、product 或 service level。
✓
可以 intentional，也可以 unintentional，例如过失或误解监管框架。
✓
可发生在金融产品/服务生命周期不同阶段，或投资价值链不同环节。
✓
可发生在 EU sustainable finance framework 的特定披露中，也可因违反 fair, clear and not misleading 等一般原则出现。
✓
可由 sustainability communication 所指实体、产品负责实体，或 ESG rating providers、third-party verifiers 等第三方触发。
✓
若不解决，即使未确认具体消费者/投资者损害或不公平竞争优势，也会削弱 sustainable finance markets and policies 的信任。
Logic Equation Cards

逻辑等式卡片：把案例背后的结构抓出来

greenwashing 不是背案例名，而是判断 claims 是否被行动、范围、数据、方法和披露支撑。

1
Greenwashing 定义
Definition
原文要点
greenwashing 是对 ESG practices 或可持续产品特征作出误导性表述，用以吸引关注环保或可持续实践的客户或投资者。
中文解释
关键不是企业用了绿色词语，而是这些词语是否真实、准确、完整、可验证。
逻辑等式
Greenwashing == 可持续 claim - 真实行动/证据/完整范围
考点提醒
正式题答案常落在 false statements about ESG practices to appeal to sustainability-minded customers。
2
三类误述
Misrepresentation
原文要点
三类包括 commitments without action、product attributes misstatements、false or misleading disclosures。
中文解释
一个看“承诺有没有行动”，一个看“产品属性是否真实”，一个看“披露是否完整可靠”。
逻辑等式
Misrepresentation == 空承诺 + 属性不实 + 披露误导
考点提醒
准确陈述环境收益不是洗绿；错误、夸大、遗漏、不可验证才是风险点。
3
声誉和系统性后果
Consequences
原文要点
greenwashing 会损害公司、品牌和市场信任，影响客户、人才、资金和合作伙伴，也可能引发诉讼和监管罚款。
中文解释
它的危害不止“被骂”，还会增加融资、合规、法律、转型和人才管理成本。
逻辑等式
Greenwashing 后果 == 信任下降 + 法律成本 + 品牌受损 + 市场信心受损
投资影响
投资分析中，洗绿风险本身可转化为声誉风险、诉讼风险、监管风险和估值折价。
4
数据反洗绿
Data Quality
原文要点
ESG ratings 和 data products 需要提高可靠性、可比性、可解释性；企业和投资者需要 traceable、credible、transparent、verified 的数据。
中文解释
披露多不等于表现好。真正有用的是能追溯、能验证、能解释的方法和数据。
逻辑等式
反洗绿数据 == 透明来源 + 清楚方法 + 完整范围 + 独立验证
考点提醒
单一指标和不透明评分系统都容易引发误导。
5
直接与间接影响
Trust
原文要点
greenwashing 直接伤害消费者信任，也间接损害公众对真实 ESG 产品和倡议的信任。
中文解释
如果假的绿色产品太多，真的绿色产品也会被怀疑，整个可持续金融市场都会受损。
逻辑等式
Greenwashing 影响 == 单个品牌信任破裂 + 整体 ESG 市场信任折损
投资影响
分析师应把信息真实性作为 ESG 投资质量的一部分，而不是只看企业 ESG 标签。
6
Greenhushing
Silence Risk
原文要点
greenhushing 指企业因担心被追责或误解，选择少披露或不披露可持续进展。
中文解释
这是 greenwashing 的反向副作用：规则不清或处罚压力大时，真实进展也可能被压低披露。
逻辑等式
Greenhushing == 真实进展 + 害怕误解/追责 → 少说或不说
考点提醒
不要把 greenhushing 误认为夸大，它是沉默或缩减披露。
7
Scopewashing
Scope Gap
原文要点
scopewashing 是用某个正面领域掩盖其他负面影响，或披露排放/影响范围不完整。
中文解释
只讲“我直接排放少”，不讲供应链、能源、运输、材料带来的间接影响，就是典型风险。
逻辑等式
Scopewashing == 局部正面 + 范围遗漏 → 整体影响被美化
投资影响
审查企业可持续声明时，要问边界：Scope 1/2/3、供应链、生命周期是否都覆盖。
8
Competence greenwashing
People Capability
原文要点
competence greenwashing 指人员或组织夸大 ESG 知识、技能、经验和职位能力。
中文解释
有 ESG 头衔或证书缩写，不等于有足够实务能力。要看真实教育背景、经验和专业团队结构。
逻辑等式
Competence risk == ESG 标签/头衔 > 实际知识/经验/团队能力
考点提醒
PDF 建议建立真正 ESG 专家团队，并让 finance 与 natural science 等背景互补。
9
ESA 七特征
Core Characteristics
原文要点
ESA 认为 greenwashing 可因遗漏或虚假信息造成，可在实体/产品/服务层面发生，可故意或非故意，可由不同价值链主体触发，并会损害市场信任。
中文解释
ESA 的框架把 greenwashing 从“广告问题”扩展到整个金融产品生命周期和投资价值链。
逻辑等式
ESA greenwashing == 信息误导 + 层级广 + 主体广 + 阶段广 + 可故意/非故意 + 损害信任
考点提醒
“only triggered by third parties” 和 “must be intentional” 都是典型错误。
10
监管应对
Regulation
原文要点
EU、UK、IOSCO、France、US、Japan 等都提出或实施反洗绿规则、披露要求、标签规则、验证要求或监管指南。
中文解释
监管重点从“能不能说绿色”转向“说之前有没有证据，是否完整披露，是否可验证，是否误导投资者/消费者”。
逻辑等式
反洗绿监管 == substantiation + clear disclosure + verification + penalties
实务提醒
监管内容变化快，实务引用时要查最新正式文件。

看范围

Scope 是最常见破口

只讲产品、工厂、直接排放，不讲供应链、生命周期和间接影响，往往就是 scope 问题。

看证据

Evidence 是判断底线

环保声明需要科学证据、计算方法、数据来源和可验证支持，不能只靠标签或颜色。

看比较

Comparison 要同类可比

与竞争对手比较时，要做 like-for-like comparison，否则也可能误导。

Regulation Map

监管地图：不同地区都在把“绿色声明”变成可验证事项

考试只需掌握各监管方向的功能，不必背完整法规细节；实务中请查最新正式文件。

EU Green Claims Directive / Ecolabel / Labeling

Green Claims Directive: 要求明确环境声明可靠、可比、可验证；证据需可信、科学、考虑国际标准和生命周期分析，并在声明前由独立审计验证。
Penalties: 处罚需有效、相称、有威慑力，可能包括罚款、没收收入、暂时排除公共采购和公共资金。
EU Ecolabel: 官方自愿标签，强调第三方验证、低环境影响和全生命周期标准。
Stricter labeling: 限制新公共标签计划，私营计划需证明 added value； aggregated scores labels 不再允许，因为可能掩盖完整图景。

UK Green Claims Code / FCA

Green Claims Code: CMA 六原则：truthful and accurate、clear and unambiguous、不遗漏重要信息、比较公平有意义、考虑 full life cycle、substantiated。
CMA: 可调查企业声明并要求更改；未配合可能进入诉讼，带来罚款和声誉损害风险。
FCA: 反洗绿规则和产品标签，限制 green/sustainable 等术语，防止夸大、误导或无依据 ESG credentials。

IOSCO Asset Managers / Ratings Providers

Asset management: 对资产管理人的 sustainability-related practices、policies、procedures、disclosure、terminology 和投资者教育提出建议。
ESG ratings/data: 关注 ESG ratings and data products providers 的治理、流程和方法透明度，因为许多地区尚无完整监管框架。
目标: 让可持续信息更一致、可比，防止 greenwashing，并增强投资者信心。

France / US / Japan 其他监管方向

France: 声称产品 carbon-neutral 时，需报告产品全生命周期温室气体排放。
US: SEC proposed Names Rule 和 ESG Disclosure Rule，关注基金名称和 ESG 策略表述，也涉及 GHG emissions 相关信息、数据、指标和策略。
Japan: FSA 指南定义 ESG Public Funds 范围，并关注 ESG Public Funds 的披露和管理 checkpoints。
Cases

案例区：每个案例都按“claim vs issue”拆

案例不用死背细节，重点看误导发生在哪里：范围、证据、生命周期、供应链、披露完整性或真实行动。

HSBC

讲转型融资，却遗漏自身融资排放

Claim：广告强调为客户净零转型提供融资、植树锁碳等正面行动。

Issue：监管关注其未充分说明自身对排放行业融资的贡献，未来环境声明需要充分限定，不应遗漏重大信息。

逻辑等式：HSBC 案例 == 正面转型 claim - financed emissions context。

Nestle / Coca-Cola

包装和塑料声明要看外部依赖和实际结果

Nestle：可回收/可重复使用包装、减少原生塑料、净零路线图等声明，需要考虑政府回收设施、消费者行为、供应链排放和塑料污染现实。

Coca-Cola：承诺回收每售出一个瓶罐对应一个瓶罐，但同时被批评为主要塑料污染者，recycled/ocean-bound plastic 声明也可能误导。

逻辑等式：包装 claim == 可回收说法 + 外部回收条件 + 实际污染结果 + 供应链边界。

ExxonMobil / BP

气候友好形象与资本支出方向不一致

ExxonMobil：公开谈解决气候变化，但仍维持大量化石燃料资本支出，并面临污染罚款。

BP：品牌转向绿色形象、宣传低碳能源产品，但被批评其大部分年度支出仍在油气方向。

逻辑等式：能源公司洗绿风险 == 气候友好 claim - fossil fuel spending reality。

Walmart / Volkswagen

供应链和技术作弊都能变成监管处罚

Walmart：低碳运营模式可能忽视供应链排放；纺织品 bamboo/eco-friendly 声明被指实际涉及 rayon 生产和有害污染。

Volkswagen：营销低排放环保车辆，但通过软件识别测试并暂时降低排放，正常驾驶排放远高于限制，后续罚款和和解金额巨大。

逻辑等式：监管处罚案例 == claim 与实际生产/技术行为冲突。

Fast Fashion

绿色形象不能遮住高周转污染模式

Claim：服装企业可能使用环保材料、绿色形象或可持续标签。

Issue：快时尚模式鼓励高频周转，合成纤维和石油基产品最终进入填埋或焚烧；具体计量和同类比较能降低误导风险。

逻辑等式：Fast fashion 风险 == 单品绿色 claim - 商业模式整体环境影响。

Danish FSA

基金披露不清、不一致、不完整

Claim：八只基金以 sustainable investments 为目标。

Issue：prospectuses 和 KIIDs 中 sustainability disclosures 过于泛化，部分关键信息不清楚、不一致或不完整，KIID 还缺少目标描述。

Outcome：缺陷涉及重大问题，违反 SFDR 和 EU Taxonomy 要求，Danish FSA 使用监管命令等工具；ESMA 也确认 SFDR 违规可采取 enforcement action。

逻辑等式：基金洗绿风险 == 产品实际投资/目标 - pre-contractual disclosure。

Common Traps

易错点：这节最爱考“绝对化选项”

看到 only、must、always 这类词，尤其要小心。

易错 1：以为 greenwashing 必须故意

ESA 明确包括 intentional 和 unintentional，过失或误解监管框架也可能造成洗绿。

易错 2：以为只能由第三方评级机构触发

可以由被表述实体、产品负责实体，也可以由 ESG rating providers 或第三方验证者触发。

易错 3：只要没有明确损害就不算严重

ESA 强调即便未确认即时损害或不公平竞争优势，greenwashing 也会削弱可持续金融市场和政策信任。

易错 4：把 greenhushing 当成 greenwashing

greenhushing 是担心争议而少披露或沉默；greenwashing 是误导性表述。

易错 5：只看直接排放

Scopewashing 常见于只披露直接排放，不披露能源、运输、材料或供应链等间接影响。

易错 6：把 ESG 分数高等同于 ESG 表现好

PDF 提醒一些评分系统可能更奖励披露，而非真实环境表现；要看方法、权重和实际绩效。

考前压缩：一屏背完 Module 4

总式
Greenwashing == claim 与 evidence/action/scope 不一致。
定义
false statements about ESG practices to attract sustainability-minded customers。
三类误述
空承诺、产品属性误述、误导性披露。
核心后果
信任、声誉、诉讼、罚款、融资、人才和市场信心受损。
数据反制
透明来源、清楚方法、完整范围、供应链纳入、第三方验证。
Greenhushing
怕被质疑而减少披露。
Scopewashing
用局部正面或部分范围美化整体。
Competence
ESG 头衔/证书/自我标签大于真实能力。
ESA
可遗漏或虚假、可多层级、多主体、多阶段、可故意或非故意、最终损害信任。
Danish FSA
基金披露不清、不一致、不完整，可违反 SFDR 和 EU Taxonomy。
Self Check

点击选项后会显示答案。题眼训练重点：定义、ESA 特征、not example、scopewashing、regulatory consequences。

Q1正式题改编
Greenwashing refers to companies:
答案：C。A 更接近 scopewashing；B 是正常的 responsible investment policy engagement，不是 greenwashing 定义。
Q2正式题改编
Which of the following is a core greenwashing characteristic set out by the European Supervisory Agencies?
答案：C。ESA 特征强调损害市场信任；A 和 B 都过于绝对。
Q3正式题改编
Which of the following is not an example of greenwashing?
答案：A。题眼是 not。准确陈述不是 greenwashing；B 和 C 都有 claim 与事实/范围不一致的问题。
Q4类型区分
A company highlights direct factory emissions but omits emissions from energy, transport, materials, and supply chains. This is closest to:
答案：B。只披露部分范围、遗漏间接影响，是 scopewashing 的典型题眼。
Q5类型区分
A firm with real sustainability progress chooses to communicate less because it fears backlash or misinterpretation. This is closest to:
答案：A。greenhushing 是少说或不说，不是夸大。
Q6数据反制
Which practice best helps combat greenwashing?
答案：B。反制核心是可追溯、可信、透明、可验证，而不是标签或绿色视觉。
Q7监管
The UK CMA Green Claims Code requires environmental claims to be all of the following except:
答案：C。Green Claims Code 要求不遗漏重要信息，比较公平有意义，并考虑 full life cycle。
Q8Danish FSA
The Danish FSA review of sustainable funds most directly highlights which greenwashing risk?
答案：B。Danish FSA 案例的题眼是 prospectus/KIID 中披露不清、不一致、不完整，并可能违反 SFDR 和 EU Taxonomy。
